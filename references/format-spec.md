# 两版默认格式

脚本已经内置下面所有参数，平时不用读本文。用户问“默认是什么格式”、或要你核对某项格式时再查。这些都是**默认值**：用户明确要求改的，按用户的来（写法见 [job.md](job.md)）。

## 来源和优先级

- A 版依据《信息学院学年论文细则.docx》附件 3（`sources/A/`）；B 版依据用户提供的五份 `.doc` 模板（`sources/B/`）。
- 同一属性按这个顺序取值：**用户明确要求 > 模板上的文字标注 > 模板文件的实际格式 > 本技能的保守处理**。例如 B 版摘要示例实际是四号，但文字标注写“五号宋体”，就用五号。
- 创建本技能时用户定下的默认：B 版不要英文摘要；两版都不显示页脚页码（目录仍有页码）；日期默认当天、放在封面第一页底部。
- 原模板里的题目、姓名、课程名只是示例，不是要求。
- 字数和文献数量：写作时用户没提要求，A、B 都默认正文不少于 5000 字、参考文献至少 6 篇（A 版细则原文要求，B 版沿用）；只排版时不检查、不补写。

## 页面

| 项目 | A：本科学年论文 | B：课程期末大作业 |
|---|---|---|
| 纸张 | A4 纵向 | A4 纵向 |
| 上下边距 | 2.54 厘米 | 2.54 厘米 |
| 左右边距 | 各 3.175 厘米 | 左约 3.00、右约 2.20 厘米 |
| 页眉 | 非封面页：左“专业＋专业本科学年论文”，右题目；小五宋体，下有细横线 | 无 |
| 页脚 | 空白（不显示页码） | 空白（不显示页码） |
| 校徽 | 绿色原校徽，靠左，宽约 10.27 厘米 | 红色原校徽，靠左，宽约 8.92 厘米 |

换校徽颜色时只换图片，宽度用当前版式的宽度，高度按原图比例。

## 封面

| 元素 | A | B |
|---|---|---|
| 大标题 | “本科学年论文(设计)”，36 磅宋体 | “《课程名》”“期末大作业”两行，36 磅黑体 |
| 题目 | “论文题目：”＋题目，三号黑体，下划线 | “题目：”＋题目，三号黑体，下划线 |
| 信息栏 | 学生姓名、学号、专业、班级、指导教师：三号宋体，内容在横线上居中 | 学生姓名、学号、专业、班级（无指导教师） |
| 完成日期 | 第一页版心底部居中，18 磅 | 同左（日期数字加粗） |

内容太长时脚本会自动处理（平衡换行、续行对齐横线区、按需收紧封面空白和行距），**不缩小字号**，保证日期留在第一页。实在放不下会提示你问用户缩短内容或允许缩小字号。

## 顺序与分页

- A：封面 → 目录 → 中文摘要 → 英文摘要 → 正文 → 参考文献。
- B：封面 → 中文摘要 → 目录 → 正文 → 参考文献。
- 封面、目录、摘要、正文各自另起一页；参考文献另起一页。目录不包含摘要。
- 正文页码从 1 开始（目录里显示）；摘要页码用罗马数字（只在用户要求显示页码时可见）。

## 字体字号（三号 16、四号 14、小四 12、五号 10.5、小五 9 磅）

| 内容 | 默认 |
|---|---|
| 正文 | 五号宋体，英文 Times New Roman；两端对齐；首行缩进 2 字符；固定行距 20 磅 |
| 一级标题“一、” | 四号黑体，居中，段前段后各 1.5 行 |
| 二级标题“（一）” | 小四黑体，左对齐，首行缩进 1.5 字符，段前段后各 0.5 行 |
| 三级标题“1.” | 五号黑体，左缩进 2 字符，段后 6 磅 |
| 序言标题 | 四号黑体，居中 |
| “目 录” | 三号黑体，居中 |
| 目录条目 | 一级四号黑体；二、三级四号宋体；右侧点线和页码 |
| 摘要页题目 | 三号黑体，居中 |
| “内 容 摘 要” | 四号黑体，居中 |
| 中文摘要正文 | 五号宋体，1.5 倍行距，首行缩进 2 字符 |
| “关键词：” / 关键词 | 四号黑体 / 五号黑体，词之间 3 个空格 |
| 英文题目 / “Abstract” | 三号 / 四号 Times New Roman 加粗，居中 |
| 英文摘要 / “Key words：” | 五号 Times New Roman / 四号加粗，词项五号加粗 |
| “参 考 文 献” | 三号黑体，居中 |
| 参考文献条目 | 五号宋体 / Times New Roman，1.5 倍行距 |

**固定 20 磅、1.5 倍行距、段前段后 1.5 行是三个不同的东西，不能混用。**

## 图表公式（模板没有规定，脚本的保守处理）

表题在表上，图题在图下，都是五号居中；图片和表格不超出版心、按比例缩放；表格整体居中，表头跨页重复；图片段落不用固定行距，避免被裁掉。
