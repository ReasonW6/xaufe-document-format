# 两版默认格式

脚本已内置下面所有参数，用户问默认格式或要你核对某项时再查。这些都是**默认值**：用户明确要求改的按用户的来（写法见 [job.md](job.md)）。

## 来源和优先级

- A 版依据《信息学院学年论文细则.docx》附件 3（`sources/A/`）；B 版依据用户提供的五份 `.doc` 模板（`sources/B/`）。
- 同一属性按这个顺序取值：**用户明确要求 > 模板上的文字标注 > 模板文件的实际格式 > 本技能的保守处理**。例如 B 版摘要示例实际是四号，但文字标注写“五号宋体”，就用五号。
- 创建本技能时用户定下的默认：B 版不要英文摘要；两版都不显示页脚页码（目录仍有页码）；日期默认当天、放在封面第一页底部。
- 学校另有要求（两版都用）：题目 24 字以内，中文摘要 150～300 字，只排版也要改到范围内；正文篇幅和文献数量见 [content.md](content.md)。

## 顺序与分页

- A：封面 → 目录 → 中文摘要 → 英文摘要 → 正文 → 参考文献。
- B：封面 → 中文摘要 → 目录 → 正文 → 参考文献。
- 封面、目录、摘要、正文各自另起一页；参考文献另起一页。目录不包含摘要。
- 正文页码从 1 开始，一直接到参考文献（目录里显示）；摘要和目录这些前置部分用罗马数字 I、II… 连续编号（只在用户要求显示页码时可见）。

## 字体字号（三号 16、四号 14、小四 12、五号 10.5、小五 9 磅）

| 内容 | 默认 |
|---|---|
| 正文 | 五号宋体，英文 Times New Roman；两端对齐；首行缩进 2 字符；固定行距 20 磅 |
| 一级标题“一、” | 四号黑体，居中，段前段后各 1.5 行 |
| 二级标题“（一）” | 小四黑体，左对齐，首行缩进 1.5 字符，段前段后各 0.5 行 |
| 三级标题“1.” | 五号黑体，左缩进 2 字符，段后 6 磅 |
| 序言标题 | 四号黑体，居中 |
| “目 录” | 三号黑体，居中 |
| 目录条目 | 一级四号黑体；二、三级四号宋体；右侧点线和页码 |
| 摘要页题目 | 三号黑体，居中 |
| “内 容 摘 要” | 四号黑体，居中 |
| 中文摘要正文 | 五号宋体，固定行距 20 磅，首行缩进 2 字符 |
| “关键词：” / 关键词 | 四号黑体 / 五号黑体，词之间 3 个空格 |
| 英文题目 / “Abstract” | 三号 / 四号 Times New Roman 加粗，居中 |
| 英文摘要 / “Key words：” | 五号 Times New Roman / 四号加粗，词项五号加粗 |
| “参 考 文 献” | 三号黑体，居中 |
| 参考文献条目 | 五号宋体 / Times New Roman，固定行距 20 磅，左对齐 |

**文字段落（正文、摘要、关键词、参考文献、图表题）都是固定行距 20 磅；图片和公式行不用固定行距（会被裁掉）。固定 20 磅和段前段后 1.5 行是两回事，不能混用。**

## 图表公式（学校要求）

- **图**：图题在图下，五号黑体居中（“图1 …”）；图与上文、图名与下文各空一行；先文后图、图不跨节。
- **表**：表题在表上，五号黑体居中；三线表，第 1、3 条线 1.5 磅，第 2 条 0.25 磅，不要竖线；全表单位相同时单位放表右上方，不写“单位”二字；表注小五宋体放表下，不写“注”“附注”，整表说明以“说明”开头；表格与上下文各空一行；先文后表、表不跨节；表格整体居中，跨页重复表头。
- **公式**：另起一行居中，编号“（1）”按全文顺序放在行末，中间不加虚线；变量斜体，字体字号和正文一致、不加粗、不加大行距；量和单位按 GB 3100～3102—93，不用废弃的单位。
- 每个表、每张图都要有题；原稿没有的，`run` 会提醒（不替用户编题目）。用了他人的图表要注明出处；目录只用 Word 自动目录，不加图表目录。
- 正文里有长网址的段落改为左对齐，免得网址前一行被拉开；代码每行一段，等宽字体小五。
