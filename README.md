# xaufe-document-format

让 AI 助手按**西安财经大学**的模板写作、排版、检查 Word 文档的 Agent Skill。

支持两套版式：**A 本科学年论文**、**B 课程期末大作业**。成品带原校徽封面、目录、摘要和页眉，最后只交付一个 `.docx`。

> 非官方项目，与西安财经大学没有隶属关系。格式以学校、学院的最新通知为准。

## 能做什么

- **两套版式、两枚校徽，自由搭配**：A 默认绿校徽，B 默认红校徽，A 配红、B 配绿都可以。
- **写不写内容，按你说的来**：
  - 给了完整文档或说“只排版”，一个字都不改。
  - 只给了题目或方向，先问清主题和内容再写。
  - 给了提纲或草稿，就在你的材料上写完整。
- **已有 Word 一键套模板**：自动识别标题、摘要、关键词、参考文献，补上目录、摘要分页和分节页码。
- **长封面自动适配**：题目、课程名再长也自动换行对齐，完成日期始终留在第一页底部，字号不变。
- **参考文献不编造，两层核实**：写作时先检索，再用 DOI、ISBN 或原文页面核对“文献是否存在、信息是否一致”（已验证 / 信息不一致 / 无法验证 / 排除），并单独核对“引用的那句话在原文里有没有依据”。交付时附一张核实清单。没有出处的具体数字、对不上的引用序号、跳号的标题都会被拦下。
- **两层格式验收**：
  - 静态检查读 Word 的实际生效格式（字体字号、行距缩进、固定行距不小于字号、页边距、分节和各节页码格式、页眉页脚、封面、校徽、目录、表格）。正文各角色的段落和字体基准是一份独立的固定参数表（`assets/checks/audit-baseline.json`），不调用排版器；封面的期望版式是用同一份母版和封面适配规则重新算出来再比对的，这一部分和排版器共用逻辑，不算完全独立。
  - 渲染后检查量的是办公软件真实导出的 PDF，不调用排版器：越界（左右和上下）、空白页、文字重叠（按字号算基线距离）、文字压图、页眉折行压进正文、页眉页脚、页码是否连续（摘要和目录 I、II…，正文从 1 起）、字体替代。版心和“该不该有页眉、页码”这两项期望来自 Word 文件里的节设置和记录下来的格式要求（读取时用到 `customization.py` 的有效格式合并），其余全部从 PDF 上量。之后再逐页看图。
- **只排版时逐字保真**：对照登记的原稿，少一个字、改一个字、多一个字都不交付；用户同意的增删要明确记下。
- **脚本做不到的格式也有验收**：手工处理的副本用 `adopt` 重新过渲染检查和原稿比对，和模板默认不同的地方会写进给用户的说明。
- **出错能自己改**：没通过时列出每个问题的位置（第几页、哪一段、该改哪个输入）、实际与应为、可能原因和改法；连续 3 次修改都没有进展（或总共 8 次不过）就停下来如实报告。
- **如实说明验收范围**：没有办公软件时照样交付 Word，但明确是“静态验收”，不会说成看过版面；渲染机器缺字体时也会说明。
- **默认值都能改**：字体、字号、页码、页眉、英文摘要等；多轮修改只改你这次说的那一项。

## 两套版式

| | A：本科学年论文 | B：课程期末大作业 |
|---|---|---|
| 依据 | 《信息学院学年论文细则》 | 课程期末大作业五份模板 |
| 默认校徽 | 绿色 | 红色 |
| 封面填写项 | 题目、姓名、学号、专业、班级、指导教师、完成日期 | 课程名称、题目、姓名、学号、专业、班级、完成日期 |
| 文档顺序 | 封面 → 目录 → 中文摘要 → 英文摘要 → 正文 → 参考文献 | 封面 → 中文摘要 → 目录 → 正文 → 参考文献 |
| 页眉 | 左侧专业与文种，右侧题目 | 无 |
| 正文 | 五号宋体，固定 20 磅行距，首行缩进 2 字符 | 相同 |
| 页脚页码 | 默认不显示（目录仍有页码） | 默认不显示（目录仍有页码） |

完整的默认参数和每项的出处见 [references/format-spec.md](references/format-spec.md)。

## 安装

在 Claude Code 中使用，把仓库克隆到技能目录，再装依赖：

```bash
git clone https://github.com/ReasonW6/xaufe-document-format ~/.claude/skills/xaufe-document-format
```

```bash
python -m pip install -r ~/.claude/skills/xaufe-document-format/requirements.txt
```

- Windows 上 `~` 就是 `C:\Users\你的用户名`。
- 只想在某个项目里用，就克隆到该项目的 `.claude/skills/` 下。
- 其他支持 Agent Skills（`SKILL.md`）的工具，把整个文件夹放进它的技能目录即可。

## 怎么用

直接用自然语言说要求，助手会自己调用这个技能：

```text
用西财 B 版模板帮我写一篇《Python程序设计》期末大作业，方向是 Python 在数据分析中的应用。
```

```text
把 D:\论文\初稿.docx 按西财 A 版学年论文格式排一下，只排版，内容别动。
```

```text
封面换成红色校徽，正文改成小四号，其他不变。
```

大致流程：

1. 选版式。没说 A 还是 B，助手会发一张对比表让你选。
2. 补齐封面信息。缺的项一次问完，任何一项都可以选“留空自己填”。完成日期默认是今天。
3. 写作或排版。
4. 实际分页并逐页检查。
5. 交付一个 Word。

## 试跑示例

```bash
python -X utf8 scripts/xaufe.py new --out 技能目录外/示例.docx --source examples/B/原稿.txt
```

`原稿.txt` 是这个示例的“用户原稿”：示例是只排版（`task` 为 `format`），`run` 会逐字对照原稿，多一个字少一个字都不交付。把 `examples/B/job.json`、`examples/B/content.json` 和 `examples/layout-test.png` 复制进输出里的 `WORK` 文件夹，然后：

```bash
python -X utf8 scripts/xaufe.py run --work "WORK"
```

## 运行环境

- **Python 3.10+**，依赖见 [requirements.txt](requirements.txt)（python-docx、PyMuPDF、jsonschema、tzdata）。
- **办公软件（用于实际分页、刷新目录页码和生成页图）**：
  - Windows：自动调用 Microsoft Word（推荐）、WPS 或 LibreOffice。
  - macOS、Linux：只自动调用 LibreOffice。**macOS 上的 Word 不支持自动调用**（脚本能发现它，但不会去操作它）；Mac 上没装 LibreOffice 时走静态交付。
  - 都没有时照样交付 Word，并在回复里说明没做的检查。
- **联网（仅写作时）**：核对参考文献要访问 Crossref、OpenAlex、Open Library 和文献原文页面。

## 验证情况

验证分两种，不混为一谈：**静态验收**只检查 Word 文件里的格式设置；**完整验收**还要用办公软件实际分页、做渲染后检查、逐页看图。

- **自动测试**：570 多项单元和集成测试；GitHub Actions 在 Windows、macOS、Linux 上用 Python 3.10 和 3.13 跑（这三个系统上都没有 Word，实际渲染部分按“没有办公软件”的路径测）。
- **真实 Word 验收（Windows，v2 时做的；v3 改了页码规则等，Word 上还没重跑）**：8 个用例在 Word 中实际分页并逐页看图，覆盖：
  - A、B 默认版式；
  - 校徽互换；
  - 超长封面；
  - 多项格式定制；
  - 在上一版成品上再修改；
  - 不启动办公软件的静态交付；
  - 已有论文补齐结构。
- **真实 LibreOffice 验收（Linux，2026-10-22，CI 每次都跑）**：上面 8 个用例加上 20 页长文档（宽表跨页、公式、代码、长链接、图片）和带合并单元格、嵌套表、九列宽表、超大图片的原稿，共 10 个正常用例，渲染后检查全部通过、除静态用例外都是完整验收，页图人工抽看过。其中超长题目的用例第一次会因页眉折行压进正文（HEADER_OVERFLOW）被拦下，按提示写短页眉后第二次通过，验证了“拦下—按提示改—再验收”这条路。另有 2 个必须被拦下的缺陷用例（行距小于字号、原稿里的空白页），都被拦下。脚本里任何一项不满足，CI 就失败。这台机器没有宋体、黑体，页图用替代字体，所以只证明版面逻辑，不证明和 Word 逐像素一致。
- **弱模型验收**：v2 时用 Claude Haiku 4.5 当执行者，跑了从零写作、只排版、已有 Word、多轮修改、缺信息时提问等场景，关键环节由脚本把关，不靠模型自觉。v3（目标导向的 SKILL.md、渲染后检查、失败反馈）之后还没有重跑。
- **不支持或还没实测**：macOS 上的 Word 不支持自动调用（见“运行环境”）；WPS 自动导出还没实测；v3 的改动还没在 Windows Word 上重跑。

维护时的检查命令：

```bash
python -X utf8 scripts/verify_bundle.py
```

```bash
python -X utf8 -B -m unittest discover -s tests -p "test_*.py"
```

```bash
python -X utf8 tests/run_acceptance.py --output-dir 技能目录外的空文件夹
```

改动任何文件后要重新生成 `SHA256SUMS`（确认改动都是有意的再运行 `python -X utf8 scripts/verify_bundle.py --update`），`verify_bundle.py` 会指出不一致的文件。仓库按原样字节校验，所以 `.gitattributes` 关闭了换行转换，文本文件统一用 LF。

## 注意

- AI 写的内容和找的文献，提交前请自己再读一遍、核对一遍。助手附的核实清单会标出哪些文献没能自动核实。
- 校徽图片、`sources/` 下的原始模板和细则归西安财经大学所有，这里只用于按学校格式排版。
